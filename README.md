# handwritten-xhs-cover

原图 + 标题 → 抠主体 → 并行 **3 种封面风格**：

1. **夸张大字** — 标题霸屏 + 放大主体
2. **手绘小清新** — doodle + 描边主体
3. **色块拼贴** — 大色块 + sticker 主体

## Cursor

```
@handwritten-xhs-cover 用这张原图，标题「XXX」
```
