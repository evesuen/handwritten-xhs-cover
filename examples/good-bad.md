# 正反面示例

## ✅ 好

| 特征 | 说明 |
|------|------|
| 字体 1:1 | exaggerated 只用 outline；doodle 只用 scattered；color 只用 marker |
| 颜色固定 | 用 reference 色板（红白黄 / 白黄 / 红+蓝奶油粉） |
| C 撕纸三色 | 原图还在；蓝+奶油+粉色撕纸都有；标题压在纸片上 |
| 构图像 cover ref | 大字霸屏 / doodle 散落 / 色块拼贴 |
| A 留原图底 | 天空/建筑/室内还在；黄只描在红字边缘 |
| B/C 小字短 | 画面几乎只有标题；色块空白；doodle 可留；补充字最多 1 条或没有 |

## ❌ 差

| 反例 | 原因 |
|------|------|
| 同时参考 outline+scattered | 字体四不像 |
| 从用户照片取棕色当字色 | 违反规则，应使用 reference 色板 |
| 三种 typography 混在一张 | 禁止 |
| B/C 小字太多 | 「和阳光见个面」+「今天适合散步」+ Good Day + Nice Weather — 色块变文案墙 |
| A 铺深棕色块 / 写出 Color #3E2723 | 把 reference 墙色当背景，或把 hex 印进画面 |
| C 一块蓝底托人 / 整页奶油 / 没有粉 | 色块用法错；必须撕纸拼贴且三色齐全 |
