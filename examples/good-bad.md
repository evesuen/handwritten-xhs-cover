# 正反面示例

## ✅ 好的封面感

| 特征 | 说明 |
|------|------|
| 字少 | 「要疯」「要野」各自独立，一眼读完 |
| 歪扭手写 | 笔画粗细不一，不是印刷体 |
| 用留白 | 字在墙/天空/芦苇区，人不挡脸 |
| 情绪词 | 「如果北方的冬天没有雪…」有画面有情绪 |
| 装饰克制 | 一条箭头、一圈描边、一个小印章——最多 2 种 |

## ❌ 要避免

| 反例 | 为什么不行 |
|------|------------|
| 居中黑体「今日好物推荐」 | 像电商 banner，不是小红书封面 |
| 标题 30 字挤满画面 | 信息过载，没有情绪 |
| 字压在人脸上 | 破坏主体，观感廉价 |
| 立体渐变金属字 | 像 2010 年 PPT |
| 每角都贴贴纸 | 过度设计，失去手写感 |

## 用户标题改写示例

| 用户输入 | 建议上封面 |
|----------|------------|
| 今天给大家分享一个做封面的技巧 | ❌ 太长 → 改为「封面这一步最简单」 |
| 蓝莓酸奶新品上市第二杯半价 | ❌ 太广告 → 改为「蓝朋友」或「今日蓝莓」 |
| 要自由 要浪漫 要疯 | ✅ 直接拆成散落关键词 |

## A/B 版差异示例

同一张海边人物图：

- **A 保守**：一行白字「也想分享给你」，无描边
- **B 情绪**：人物白描边 + 三行字 + 衣角涂鸦线

交付时两张都给出，让用户选。
